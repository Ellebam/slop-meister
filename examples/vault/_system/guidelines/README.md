# Writing guidelines

Keep one owner for each fact. A context note routes readers to that owner.

Use short sentences and active voice. Record current constraints, decisions and their reasons. Separate observed facts from assumptions. Give commands an expected result. Link related notes rather than copying their contents.

Keep project facts in the matching field. Keep credentials in the password manager. Store no rendered agent configuration, scripts or Git metadata in the vault. Use the external history tools for named paths only.

[Retrieval](retrieval.md) explains how to find existing knowledge.
