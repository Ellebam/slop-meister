# Session retros

The default `slopmeister-vault retro` command creates and commits one note here per session. Each note records what worked, what failed and what should change. Use the session name as its task identifier and check for an existing entry before retrying.

The [legacy log](../retro-log.md) remains available through explicit `--note _system/retro-log.md`. Do not migrate old entries or pending spills automatically.
