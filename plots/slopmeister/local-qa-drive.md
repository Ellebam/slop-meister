A change here is driven by rendering it and reading what came out, because the user of this configuration is a session that loads the rendered file. Run `bin/slopmeister render` and read every file it changed under `dist/`, then `task home:diff` to see what the installer would change on this machine, then `task check`. Where a plot or a procedure changed, read its rendered copy under `dist/` top to bottom as a session would. Where a launcher script changed, run its task from the repository root against a scratch target. `task home:install` writes outside the repository, so it runs only when the operator asks.
